# Phase 2E：独立重力补偿位置控制器

本轮保留原 `src/robot/joint_controller.py`、位置执行器、模型质量/惯量、重力、积分器及全部力限，新增 gravity_compensation.py 与 compensated_joint_controller.py。M0 始终直接使用原 JointPositionController；M1 使用新增补偿类，M2 使用同一补偿类再接提前保持保护。没有通过 live qpos 改写改善精度。

## 1. 实际执行器审计

七个 general actuator 都是无激活动力学、固定 gain、仿射 bias、直接关节传动，gear=[1,0,0,0,0,0]。七关节实际 Kp 为 [4500,4500,3500,3500,2000,2000,2000]，Kd 为 [450,450,350,350,200,200,200]。bias0=0、bias1=-Kp、bias2=-Kd，没有额外 gain 项；ctrl 单位为 rad。关节广义力与执行器输出力矩在单位 gear 下相同，单位 N·m：

```
tau_raw = Kp * (ctrl - q_actual) - Kd * qvel_actual
tau_actual = clip(tau_raw, original actuator force range)
```

前四关节力矩范围 ±87 N·m，后三关节 ±12 N·m；原 ctrlrange 与真实 MJCF 关节限位一致。加载时再次检查类型、gear、增益映射及原 force/control limited 标志，不满足条件拒绝套用本方案。夹爪执行器不由补偿模块改写，仍保持原耦合夹爪与控制。

原模型全部 body_gravcomp=0、关节 stiffness=0、流体 density/viscosity=0，重力为 [0,0,-9.81] m/s²。独立数据在零速度时手臂 qfrc_passive 必须近零；已有被动重力补偿、弹簧或未审计流体力时拒绝，避免重复补偿。非法模型仅在自动测试的独立副本中构造，正式名义模型始终不变。

## 2. 纯重力计算与输入映射

GravityCompensation 复制模型并新建独立 MjData。每次明确设置完整关节位置（含当时夹爪状态）及实际七关节地址，将所有 qvel/qacc 设零，再调用 mj_forward。按实际 jnt_dofadr 提取 qfrc_bias 的七关节分量。

一般状态的 qfrc_bias 含速度相关项，不可直接叫纯重力。本模块的“纯重力”解释依赖零速度和以上被动项审计。mj_forward 同时可能计算其他数组，但读取的零速 bias 不依赖给执行器的控制指令；它不把 qacc 或约束反力误当重力。

在已经核对的线性位置伺服映射中：

```
delta_q_gravity = gravity_generalized_force(q_actual) / Kp
q_corrected = q_ref + delta_q_gravity
```

符号来自静态平衡 Kp(ctrl-q)=gravity。比如 home 构型 J2 重力广义力约 -29.36 N·m，因此 J2 指令向负角方向修正，抵消 M0 的正向静差。单位是 N·m/(N·m/rad)=rad。并未改变模型内部重力，也未额外写 qfrc_applied；仅通过原位置执行器 ctrl 输入实现前馈。

重力在实际构型处计算；这是重力前馈，不是完整逆动力学、速度阻尼补偿或惯性前馈。因此运动期间仍可能有速度相关跟踪滞后。理想名义模型的静态误差降至数值精度不意味着真实机器人具有相同精度或参数鲁棒性。

## 3. 限制与消融

配置在首次静态试验前冻结：每关节补偿偏移上限 0.02 rad；补偿后目标裁剪到原关节/ctrl限位；总下发位置指令变化率仍为 0.35 rad/s。q_ref 必须合法且有限，重力查询拒绝 NaN/Inf。实际输出力矩始终受原 native force limits 限制，没有解除力矩约束。

CompensatedJointController 最后调用原 JointPositionController.step，后者执行真正的 ctrl 写入和一次 mj_step，以及后积分几何刷新。补偿计算只修改自己的查询数据，不修改 live qpos/qvel。

`controller.enabled=False` 可关闭补偿；切换后仍有同一指令变化率约束。自动测试在相同状态下核对“关闭补偿”与原伺服的逐步 qpos/qvel 完全一致。正式 M0 直接用原类，不依靠一个暗中修改过的“关闭补偿版”作为基线。

原执行器的旧 command_rate_limit_steps 计数器假定 ctrl 追踪的就是 q_ref，这对补偿类已不成立。本轮以 control_signals.csv 中的 effective_rate_limited 和汇总 effective_rate_limit_steps 为准；保留原计数器并明确标注为 legacy，而不将重力偏移误说成每步都触发限速。

## 4. 静态先验验收与真实记录

无近障碍三构型：home、保存的 D 起点、D 历史首次违规时的参考构型。每个构型 M0/M1 各实际积分一次，起始初始化仅在 t=0，之后通过动力学保持；最后250个物理步（0.5 s）检查稳态误差与峰峰值。

进入障碍试验前要求：全部静态保持稳定成功、无力矩饱和、稳态七关节峰峰值均小于 1e-4 rad，且每个构型的 M1 TCP 静差都小于 M0。实际三个构型 M0 TCP 静差约 6.724、6.724、5.444 mm；M1 在匹配的理想仿真模型中约 1e-13 m。完整七关节稳态误差、真实力矩、最大速度、初始化加速度及稳态变化量见静态运行目录与最终报告，不能以这些数值替代实机验证。

## 5. 数据与未来接口

tracking.csv 保留原 q_path 来源、未补偿的 q_ref/dq_ref/ddq_ref、实际 ctrl、q_actual/qvel、TCP 及安全信息。新增 control_signals.csv 记录补偿查询量/偏移、真实执行器力矩、原线性映射重算值、饱和、限位/限速介入、控制变化率和变化率差分；计算成本分为重力算法、预测算法与包含物理/检查/I/O的总墙钟时间。

后续若研究残差控制，可在经过单独验收后考虑 `q_ref + delta_q_gravity + bounded_delta_q_residual`，再统一应用原位置限位、总变化率和力矩限制。观测可包含实际 q/qvel、参考及导数、误差、ctrl、补偿和连杆级间隙。这里仅说明接口顺序；本阶段没有实现任何 RL 网络、训练循环或残差环境。
