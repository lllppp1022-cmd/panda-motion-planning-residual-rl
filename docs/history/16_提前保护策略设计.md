# Phase 2E：实验性短时动力学预警与补偿保持

本模块是名义模型下的实验性 look-ahead，不是形式化安全屏障、连续碰撞保证或实机认证。硬性失败条件始终是原5 mm实际表面间隙与原禁止接触规则。没有改动原 CollisionChecker、RRT 或 Phase2C 执行器。

## 1. 先预测，再对照，再主动干预

冻结配置：预测周期0.05 s，预测时域0.30 s；shadow内部仍以0.002 s积分，每0.02 s查询全部274个审计配对。当前实际状态仍在每个物理步按原Phase2C规则监控，不用TCP到障碍中心距离替代连杆几何。

第一阶段仅shadow记录，不改变原控制输入：对原D路径seed42以及8 mm规划seed123路径，分别运行M0/M1、0.15 rad/s，共4次。将预测样本目标物理步与随后实际tracking.csv对齐，只比较实际仍执行原参考的部分；触发停止后两者政策不同，不混入误差验证。

进入主动pilot前冻结门槛：可对齐的最大七关节预测误差≤1e-5 rad、最大间隙误差≤0.1 mm、已知实际失败必须提前预警、单次预测计算P95<0.10 s。这个计算预算不是2 ms硬实时保证。完整 shadow_gate.json 和逐样本对照保留，失败则不扩大主动试验。

随后两例M2主动pilot，只有到达目标或实际稳定安全停住且无预测异常，才开展有界正式对照。没有在正式结果出来后改变阈值来制造成功。

## 2. 独立shadow状态与假设

复制原模型并新建独立数据，使用 mj_copyData 复制当前 live 完整状态，含时间、qpos/qvel、ctrl、暖启动、夹爪和mocap等，而非仅复制七维观测。预测控制器保持同一方法，并将其 command_q 延续状态复制为live控制器当前命令，避免“从实际角度重新开始限速”造成伪预测。

预测继续使用同一五次参考和原预保持时序；M1/M2的shadow继续使用相同重力补偿与native力限。预测中所有 mj_step 都作用于shadow数据，绝不额外积分live；单元测试对live完整积分状态逐项比较并核对实际步数未增加。

预测回答的是“若继续当前原参考会怎样”，不在shadow里递归触发主动保护。外部力/场景按当前快照延续，未来未知扰动或移动障碍不在保证范围；模型参数错误也会破坏预测。名义模型预测与实际近乎数值一致是同模型一致性验证，不是对真实误差分布的认证。

## 3. 7 mm预警与5 mm实际失败不能混淆

预警判据是预测最低间隙≤7 mm，含相对硬门槛2 mm缓冲，或预测中出现非法状态。当前几何间隙也纳入这一保守判断。预测只有每20 ms的离散几何采样，不能证明采样间绝对无碰撞。

“预测触及7 mm”不等于“已经违反5 mm”，也不等于一定会违反5 mm。shadow试验中，M0两个已知失败分别提前约0.320和0.488 s预警，但M1有一个收到预警的路径最终仍满足5 mm并正常到达。此类保守预警会在M2造成不必要中止，必须报告。

## 4. 当前主动策略：提前暂停并受限补偿保持

本版实现的是**提前停止参考推进，转入受限补偿保持**；没有声称实现了连续速度重定时或具有刹车距离证明的减速曲线。

预警后在下一控制边界提出 predictive_guard_stop 意图，原执行器记录停止时间/实际构型，冻结轨迹时钟并将保持目标设为当前实际构型。新增控制器继续对该保持目标添加重力补偿，保留原0.35 rad/s命令变化限制和native力限，继续积分至少原0.5 s保持窗口，记录惯性及平衡响应。

重力补偿有助于避免原控制器重新设保持目标后再次产生重力静差，但不能消除全部惯性、饱和或接触响应。预测异常时主动模式保守停止并归档错误，不把缺失预测当安全。

## 5. 结果分类与公平对照

- success：沿原时间参考到达并通过原稳定目标条件，且没有实际间隙违规/禁止接触。
- protected_stop：因预测主动保持，未到目标；另记录是否实际无违规/无接触且速度已稳定，不能算任务完成。
- failure：实际硬门槛、接触、数值或预算等失败；如果保护之后仍发生违规，也不能当作“安全停住”。
- user_aborted：用户关闭窗口或主动中止，不混作控制成功或算法失败率中的普通试验。

以同路径/同速度的M1运行作为M2的配对反事实：若M1本来成功且无违规，而M2中止，则标记“该测试条件下保守停止”。这不能证明所有预警都是误报，但可以定量反映当前保护层降低任务完成率的代价。不得把M0到M2的改善全部归因于保护，因为其中还有重力补偿这一变化。

## 6. 原始证据与成本

predictions.json 保存观察物理步/时刻、未来目标物理步、预测q与最近配对间隙、预警、时域和实际计算耗时；它不是实际轨迹。tracking.csv/clearance.csv保留实际积分、实际接触和间隙。新增汇总分开首次预警、保护动作、第一次实际5 mm违规、第一接触、停止后位移/间隙及是否稳定。

500 Hz是仿真控制与监控的物理步频；预测计算会阻塞当前仿真循环、降低墙钟速度，不能宣称真实硬件上每2 ms都能完成本实现。正式实验报告单次预测P50/P95/最大值及摊销每实际物理步开销，三工作进程和渲染负载也会影响墙钟数值。

本阶段不自动调整预警缓冲来提升完成率，不添加学习策略。若出现保守停止，应先考虑传统参考速度重定时、可验证制动/保持策略及模型不确定性处理，并开展独立验收。
