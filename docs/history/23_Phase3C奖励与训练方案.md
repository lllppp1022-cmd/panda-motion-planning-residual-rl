# Phase3C：奖励诊断与有限多种子方案

日期2026-10-22。配置`configs/phase3c_pilot.json`在新场景规划及PPO前固定，未使用最终测试动态结果选权重。历史3B代码和数据不修改；本轮代码位于`src/experiments`，避免改变3B的源码集合。

## 历史诊断依据

从3B物理CSV、决策CSV和各更新前checkpoint重构全部78维观察、Critic值、Actor均值/标准差与动作log-prob。按原256决策rollout、正确episode_start/done和最后值bootstrap重算GAE；重新按seed42排列做80个原Adam步，属于**原数据离线重放，不是新增在线训练**。检查四份历史checkpoint参数及value loss是否一致。未完成回合的MC只能报告已观察折扣前缀，不虚构未来真实回报。

## R0与R1

R0逐字复用原环境奖励及物理定义。R1是同一次物理交互的独立重算；两版本使用同一78维观察、M3、残差上限±0.002rad、独立0.01rad/s变化率、总0.35rad/s、原位置/力矩及5mm门槛。

令 `S=本决策实际物理秒数/冻结轨迹时长T`，`Δp=冻结参考轨迹进度变化`：

```
R1 = Δp - S*(4*Lq + 4*Ltcp + 0.5*Lv + 0.1*La + 0.1*Ls + 0.01)
     + 2*真实成功 - 20*失败或超时 - 40*禁止接触
Lq   = min(1, mean((关节误差/0.001rad)^2))
Ltcp = min(1, mean((TCP误差/0.001m)^2))
Lv   = min(1, mean((速度误差/0.02rad/s)^2))
La   = mean(归一化动作^2)
Ls   = min(1, mean(相邻归一化动作差^2))
```

不增加基于“活着”的正奖励：保持/等待不推进参考，也无额外进度收益；等待增加负时间成本并折扣到达奖励。所有任务T至少8秒；未来代价上界8.71*(1+2.5/8)<20，因此对同一当前轨迹前缀，主动立即失败不能规避更大的未来跟踪成本而获利。该论证不是跨任意不同误差任务的全序保证，也不是PPO收敛证明。

对160/327/600/750决策长度、三档误差分别检查成功、早停、中途保护、末端失败的未折扣和gamma0.995折扣回报；同一任务/同误差前缀的成功必须高于失败。已有真实3B轨迹同时离线计算R0/R1，权重和尺度定义均独立于最终测试表现。原成功/安全条件不变。

## 场景、工况与传统基线

新球训练、圆柱验证、盒最终测试分别使用不同起终点、关节2姿态与障碍位置，全部RRT+Shortcut且0.005rad复核，规划20mm、执行5mm。历史D窄间隙不作为随机探索任务。最终几何可预先规划，但动态只在所有方法、checkpoint及预算选择冻结后开启。

训练按固定周期覆盖名义、Kp×0.9、质量和惯量×1.1，两个种子42/123的物理噪声种子独立。相同训练种子的R0/R1共用工况周期；PPO不接收工况或真实参数。观察、网络64×64、学习率1e-4、rollout256、batch64、5epoch及其余PPO超参数均与3B一致。

M1/M3不变。独立积分候选`ki=0.3/s`，目标积分±0.002rad、0.01rad/s残差变化率；上次延迟/噪声观测（额外旧一个物理步）提供误差反馈。积分钳位，前次总指令限速或原生力矩饱和时禁止继续积分，保护保持清零；不读取真实质量/增益补偿。训练/验证共六次真实门禁后冻结，记录其名义精度与失配改善的取舍，不宣称全局最优，也不按最终测试继续调参。

额外六次真实非零探针：训练/验证gain90各比较M3、受限误差负反馈、反向误差反馈，幅度和变化率不扩大。保存改善和恶化样本，不只挑好的动作。

## 有界训练与共同门禁

共4组（R0/R1×42/123），每组首先2048决策。此时关闭并记录未完成回合的真实保持；确定性验证gain90/mass110两个条件，完整记录所有结果。只有四组均满足：训练/验证无5mm违规或禁止接触、验证全部到达、至少2个完整失配训练回合、每次Actor/Critic更新且loss有限，才**四组一起**继续至4096。任何一组失败则所有组同停2048，不能单给R1更大预算。

第二段从原权重、优化器和Python/numpy/torch随机状态恢复，用新环境继续工况周期；这是显式分段实验，不伪称轨迹无缝连续。reset、决策真实积分、保护/退出保持分别计数。4096决策可能超过10万**物理积分**，但本轮上限始终是4096个**PPO决策**，没有10万决策训练。

每256决策保存完整rollout数组（观察、原始动作、奖励、values、GAE、returns、log_probs、episode_start），每次更新记录Actor/Critic增量、策略loss、value loss、KL、EV、优势分布并保存checkpoint。每决策记录真实高斯动作、Actor均值/标准差和R0/R1奖励，每物理步记录真实残差、有效限速及原生饱和。

## 公平评价与停止边界

2048门禁8次；正式验证/最终测试分别3条件×7方法（M1、M3、积分、四个PPO），共42次。统一物理种子9001。固定各组最终允许预算checkpoint，不选最好种子或对某奖励增加预算，不以最终集决定权重。报告每个种子，不将两种子描述为统计显著；失败误差连同完成进度和终止原因保留。

以真实到达、安全、接触、全身跟踪/TCP误差、残差及平滑性、决策与物理样本一起回答是否有额外收益。有限pilot交付后暂停，不启动100k决策训练。
