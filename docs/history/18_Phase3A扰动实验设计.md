# Phase 3A：冻结的有限扰动诊断设计

日期：2026-10-22。禁止 PPO/SAC 训练。历史 MJCF、原 M0/M1/M2、RRT 和安全判据保持不变。

## 实验前冻结

`configs/phase3a_pilot.json` 在首次规划及动力学执行前冻结；准备目录中的 `frozen_design.json` 记录源码及配置 SHA256，`history_sha256.json` 冻结历史文件。每次执行核验冻结源码，不能在同一实验中途调整控制器。历史 D seed42 以及三个新布局均保存路径证据；新布局每个最多尝试规划种子 42、123，首次成功后停止，所有失败保留。10 mm 规划门槛与 5 mm 实际执行门槛独立。

## 模型隔离与扰动定义

`nominal_controller_model` 为原模型的独立副本，只供重力/前馈参数查询。`perturbed_physics_model` 另行复制，只由真实物理积分及真实状态碰撞监控使用。模型数组和两份 MJB 的哈希逐次保存。控制器不读取实际质量、惯量、增益或阻尼来补偿；它只能使用名义参数、已知参考和上层可观测关节状态。

| 条件 | 固定扰动 |
|---|---|
| nominal | 无扰动 |
| gain_low | 七关节 Kp ×0.8，同时调整 actuator gain 和位置 bias，保留 Kd |
| damping_high | 七关节被动关节阻尼 ×1.5，保留执行器 Kd |
| mass_high | 所有有质量的运动机器人刚体质量与主惯量同时 ×1.2 |
| observation_noise | 上层关节位置独立高斯噪声，标准差0.002 rad |
| observation_delay | 上层关节位置观测延迟10步，即20 ms |
| action_delay | 上层补偿后的目标延迟10步，再经过原0.35 rad/s限速和原伺服 |
| combined | Kp×0.8、质量惯量×1.2、上述噪声、观测及动作延迟 |

只做已声明的方向和幅度，不能推断对称扰动或更大不确定性的鲁棒性。质量/惯量比例保持惯量三角不等式，检查非负、有限数值。关节/控制/力矩范围、gear、碰撞几何和5 mm门槛不变。历史XML不写入。若物理警告、非有限数值、运行异常出现，独立归为无效模型/运行，不混入有效任务成功率，并仍报告数量及原因。

观测噪声和观测延迟只作用于上层重力补偿的输入，夹爪使用实际可观测位置。原MuJoCo内置位置伺服仍直接使用内部状态。动作延迟不包含底层反馈延迟。因此这不是完整编码器噪声、速度测量噪声或网络化底层伺服试验。噪声每个物理步只采样一次；同一任务、扰动种子下M1/M3共享同一随机序列，不重新挑种子。延迟FIFO在初始化时填入初态，避免未定义缓存。

## M3推导与边界

当前单位gear位置伺服未饱和时：

`tau = Kp*(ctrl-q) - Kd*qvel`。

M1：`ctrl_desired = q_ref + clip(g_nominal(q_observed)/Kp_nominal, ±0.02 rad)`。

M3在此基础上加入 `clip((Kd_nominal/Kp_nominal)*dq_ref, ±0.02 rad)`。`Kd/Kp`单位为秒，乘参考速度rad/s后得到rad，正号用于抵消正向运动时的速度阻尼。实现用相邻已收到参考位置的后向差分估计当前参考速度，不读取未来真实状态。保持阶段强制速度前馈为0，避免保护切换时的参考跳变产生前馈冲击。位置裁剪、0.35 rad/s目标限速以及原±87/±12 Nm原生力矩限幅继续生效；不消除模型失配或加速度需求，因此不是完整逆动力学。

两种控制器从同一构型显式初始化，按原1.5 s初始保持、五次时间缩放、0.15 rad/s、0.30 rad/s²参考界限执行；500 Hz物理积分、每物理步检查全部274对。原到达要求不变：关节误差≤0.02 rad、TCP≤10 mm、速度≤0.02 rad/s并持续0.5 s。控制器补偿、噪声和延迟均通过`data.ctrl`及`mj_step`运行，正式积分后不写live qpos。

## 分组、顺序和预算

1. 两个无障碍构型，各M1/M3静态保持，共4次。
2. 历史D及新train_sphere、validation_cylinder，先名义再单因素、最后组合；名义单种子3101，其余各3101/3102，每条路径30次，共90次。
3. 完成训练/验证pilot后冻结源码哈希并开启heldout_box，同样30次。此处“训练布局”仅为未来用途，本阶段没有网络训练。测试布局几何可以预先规划，但测试动力学开启前不调参，开启后不依据测试结果优化。
4. 最多120次正式路径执行，外加4次静态和有明确标识的视频重执行。每次执行最多180 s墙钟、120 s仿真，规划每布局最多2次有界RRT搜索。不能无限重试。

两种随机种子主要检验噪声条件重复性；纯参数确定性工况重复执行不构成独立随机场景，汇总必须标明。新几何必须具有不同的实际布局和构型，不能只换种子名。所有新路径先复核10 mm规划间隙，再用保持5 mm门槛的执行检查器监控实际全身、夹爪、地面及原生接触。

## 公平指标与结论规则

逐次保留真实q_ref/q_actual/dq/ddq/ctrl/TCP/接触/间隙CSV、上层观测与噪声、前馈、实际力矩、模型参数及源码哈希。报告到达、失败、人为中止、无效运行；跟踪误差必须连同轨迹完成进度和早停原因一起读。配对时核对同路径、场景、物理模型、扰动种子和完整噪声序列。跟踪RMSE只汇总原轨迹/末端保持阶段，不能把失败后的当前姿态保护保持当作目标跟踪成功。

比较任务成功、安全违规、禁止接触连续区间、七关节/TCP RMSE、最终TCP误差、实际速度加速度、力矩饱和、实际执行仿真及墙钟时间、控制额外耗时。成功/失败均保留，原始CSV独立复算；录像只能来自正在积分的live MjData。

若M3已解决名义滞后，而失配只造成原判据内小误差，优先继续传统辨识/补偿，不能预设RL必要。只有明确可重复且幅度合理、简单传统方法未解决的残余问题才支持后续独立残差试验；本阶段不训练，也不宣称离散或预测检查具有连续/实机安全保证。
