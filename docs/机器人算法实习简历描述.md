# 机器人算法实习简历描述（按本人真实分工选用）

项目名称：七自由度Panda机械臂运动规划与模型补偿控制（MuJoCo，Python）。本项目为AI辅助个人研究工程；个人具体分工请本人核实，不应将全部自动生成/未理解代码写成独立原创贡献，也不虚构实机经验。

- 构建Panda关节伺服、FK/Jacobian和DLS位置IK，连接真实物理积分的七关节/XYZ键盘交互。
- 实现七维双向RRT-Connect、碰撞检查Shortcut与0.005rad最终复核；结合五次时间参数化执行关节路径，分离参考、指令与真实状态。
- 审计23个机器人碰撞几何和274个检查配对，通过失败案例区分规划与动态安全裕度，保留原5mm违规门槛与受限保持日志。
- 在名义/扰动物理参数隔离下对比重力、速度与受限积分补偿；最终六工况平均TCP轨迹RMSE由M3的1.154319mm降至Integral20的0.469299mm（约59.3%），限定于该测试集。
- 完成BC78/85和两个种子BC热启动PPO/积分残差PPO有限对照，记录16384决策、447208次训练物理积分，保留PPO未稳定超过强积分基线的负结果。
- 建立实际训练RGB/状态/动作/奖励/更新事件关联及冻结指标复算；历史222测试与发布轻量验收分开追溯。

不写：原创RL算法、RL全面优于传统控制、实机部署、Sim-to-Real、安全认证、统计显著性或未经核实的个人工作量。
